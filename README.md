# Ouvidoria MBFREIRE

Frontend da Ouvidoria MBFREIRE, uma aplicação web para registrar e acompanhar manifestações dos clientes da empresa em um canal centralizado e seguro.

Os clientes podem consultar suas manifestações e trocar mensagens com a equipe de ouvidoria durante o atendimento. A equipe administrativa acompanha os registros, responde aos clientes e gerencia clientes e categorias. O acesso é autenticado e cada cliente visualiza somente suas próprias informações.

O projeto foi desenvolvido com React, TypeScript e Vite.
